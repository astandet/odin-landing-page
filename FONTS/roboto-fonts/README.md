Generated by FontToolbox — https://www.fonttoolbox.com/tools/google-fonts

## Usage

1. Copy the `fonts/` directory and `fonts.css` to your project.
2. Import `fonts.css` in your HTML or CSS:
   `<link rel='stylesheet' href='./fonts.css' />`
3. Adjust `font-display` in `fonts.css` if needed.
   See https://www.fonttoolbox.com/guides/web-font-loading for options.
